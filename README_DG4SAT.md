# DG4Sat

Look4Sat + 郊狼 DG-LAB 卫星指向联动。

本项目基于 [Look4Sat](https://github.com/rt-bishop/Look4Sat) v4.4.9 的源码，在雷达页新增
`DG-LAB` 标签页：手机通过低功耗蓝牙（BLE）连接郊狼主机，用手机指向卫星；当指向与卫星的
偏离角超过启动角时自动输出，偏离越大强度越高。

> ⚠️ **安全警告**：这是控制电击设备的软件。仅限成年人在充分知情同意下使用。有心脏疾病、
> 体内电子植入物、癫痫、孕期或正在驾驶/操作机械时请勿使用。电极不要跨过胸部、颈部或头部。
> 请从最低强度开始，并保留随时点“立即停止”的习惯。本软件不提供任何担保。

## 功能

- 雷达页新增 `DG-LAB` 标签：扫描、连接、断开郊狼主机，实时显示偏转角、输出强度和电量。
- 支持郊狼 **V3**（蓝牙名 `47L121000`，服务 `0x180C`，写 `0x150A`、通知 `0x150B`）和
  **V2**（蓝牙名 `D-LAB ESTIM01`，服务 `0x180B`）。
- 可设置：
  - **启动强度**：偏离角刚超过启动角时的强度（%）。
  - **最大强度**：输出强度上限（%）。
  - **启动偏转角**：偏离角大于该值才开始输出（0–178°）。
  - **满强度偏转角**：偏离角达到该值时输出最大强度（启动角+1–180°）。
  - **输出通道**：A / B / A+B。
- 强度按百分比线性增长：
  `强度% = 启动强度 + (最大强度 − 启动强度) × clamp((偏差 − 启动角) / (满强度角 − 启动角), 0, 1)`
- 安全限制：
  - 卫星在地平线以下、传感器未就绪、未开启“自动输出”或未连接时，输出为 0。
  - 离开雷达页、应用退到后台、断开连接或点击“立即停止”都会归零/停止脉冲。
  - V3 连接后会把“最大强度”写入主机软上限（BF 命令），即使应用逻辑出错也不会超过设定值；
    该软上限会保存在主机里，断开后仍然有效。
  - 停止输出时应用会主动写入零强度；脉冲数据也是按 100 ms 窗口流式发送的。
  - **但**蓝牙链路意外断开或进程被杀时，最后一次零写入可能来不及发出。请始终把最大强度设低，
    并把主机滚轮/官方 App 作为紧急停止手段；不要依赖软件作为唯一保护。

## 使用

1. 打开郊狼主机，确保手机蓝牙已开启。
2. 在 Look4Sat 中选好卫星并进入 **雷达** 页，切换到 **DG-LAB** 标签。
3. 点 **扫描郊狼主机**（首次会请求附近的蓝牙权限），在结果中连接。（也可以用“上次设备”）
4. 设置启动强度、最大强度、启动偏转角、满强度偏转角，建议先用 5% / 20% / 10° / 60° 试。
5. 打开 **自动输出**。用手机顶部指向卫星（与雷达上的十字准星一致），偏离超过启动角后开始输出；
   转得越偏，强度越高。
6. 需要立刻停止时点 **立即停止**，或直接切走/锁屏（应用进入后台会自动解除自动输出）。

> 指向模型：使用 Android 旋转矢量传感器，手机“顶部”方向为指向，和 Look4Sat 雷达上已有的
> 十字准星一致。建议在设置里打开“传感器/罗盘”，并用罗盘偏移量校准。磁偏角由 Look4Sat
> 根据台站位置自动修正。

## 构建

- Android Studio（JDK 21，compileSdk 37）打开 `Dg4Sat` 目录。
- 命令行：`./gradlew assembleDebug`（输出在 `app/build/outputs/apk/debug/`）。
- 应用显示名（桌面图标/系统设置）为 `DG4Sat`。
- 安装包名（applicationId）为 `top.bravocn.dg4sat`，debug 和 release 使用同一个包名，
  可以直接和官方 Look4Sat 共存。源码 namespace 仍保留 Look4Sat 的
  `com.rtbishop.look4sat`（Android 允许 namespace 与 applicationId 不同）；如果连源码包名
  也要全部改成 `top.bravocn.dg4sat`，需要同时移动各模块源码目录并修改 namespace。

## 协议与实现位置

- BLE 连接、100 ms 输出循环、软上限、V2/V3 编解码：
  `core/data/.../framework/CoyoteLink.kt`、`CoyoteProtocol.kt`
- 指向/强度数学：`core/domain/.../utility/CoyoteCalculator.kt`
- 状态与设置：`core/domain/.../model/Coyote.kt`、`SettingsRepo.kt`
- 雷达页联动与状态机：`feature/radar/.../RadarViewModel.kt`
- UI：`feature/radar/.../DgLabPage.kt`、`RadarScreen.kt`

协议参考：[dglab-bluetooth-protocol](https://github.com/dungeonlab-open/dglab-bluetooth-protocol)
（V2/V3 README）。

## 备注

- 如果之前把 V3 的软上限设得很低、现在想恢复，请在本应用把“最大强度”调到 100% 并重新连接
  一次（会重新下发 BF 命令），或使用官方 App 调整。
- V2 没有软上限命令，最大强度仅由本应用的绝对强度写入来限制。
- 输出脉冲固定为约 10 Hz（100 ms 周期）、脉冲强度 100（V3）/ Z=20（V2），只调节通道强度。
